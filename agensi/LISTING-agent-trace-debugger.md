# Agensi listing copy: agent-trace-debugger

**Title:** Agent Trace Debugger — replay a Claude agent step by step
**Price:** Free
**Category:** Testing & Debugging
**Summary (<=300 chars):** Turn a Claude tool-use conversation (messages array) into a readable timeline of thoughts, tool calls and results, and flag errors, orphaned calls, loops and unrecovered failures with a concrete fix for each.
**Tags (<=10):** claude, agent, tool-use, debugging, trace, observability, messages-api, llm-ops, replay, agents
**Use cases:**
1. Find why an agent looped or gave a wrong answer
2. Check for orphaned tool_use / missing tool_result
3. Review how an agent recovered from a tool error

**Link back:** https://agentreplay.vercel.app (source github.com/ferhatatagun/agent-replay)
